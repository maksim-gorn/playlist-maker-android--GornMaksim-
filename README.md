# Playlist Maker

Android application for music search and playlist management using the iTunes Search API.

## Requirements

Android Studio: Ladybug 2024.2.1 or newer
Gradle: 8.13 or newer
Kotlin: 2.0.21
Target SDK: 36 (Android 16)

## Build instructions

# 1. Clone the repository

```bash
git clone https://github.com/maksim-gorn/playlist-maker-android--GornMaksim-.git
```

# 2. Get Gradle

if oppening the project folder in Android Studio Ladybug (2024.2.1) or newer.  
The IDE will automatically download Gradle 8.13 and required dependencies.

# 3. Build the prject

```bash
gradlew.bat assembleDebug
```
